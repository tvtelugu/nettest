NetMirror API

Scraper and stream resolver for the Netflix catalog mirror.

Endpoints
GET /api/home Homepage categories ▾

Fetches the live homepage and parses every category row. Personalized rows like "Continue Watching" are filtered out.

Response 
{
  "success": true,
  "categories": [
    {
      "category": "Popular Titles",
      "itemsCount": 35,
      "items": [
        {
          "id": "81288983",
          "image": "https://imgcdn.kim/poster/341/81288983.jpg"
        }
      ]
    }
  ]
}
Live response
GET /api/series TV series listings ▾

Scrapes the TV series section. Same response shape as /api/home.

Live response
GET /api/movies Movie listings ▾

Scrapes the movies section. Same response shape as /api/home.

Live response
GET /api/search Search titles ▾

Proxies a search query and returns matching title IDs with names.

Query parameters
q required Search keyword
Response 
{
  "success": true,
  "data": {
    "searchResult": [
      {
        "id": "81288983",
        "t": "The Diplomat"
      }
    ]
  }
}
Live response
GET /api/title/:id Title metadata ▾

Returns full metadata for a title including name, year, rating, runtime, cast, genre, description, and season/episode list for series.

Path parameters
id required Netflix title ID
Response 
{
  "success": true,
  "data": {
    "title": "The Diplomat",
    "year": "2023",
    "runtime": "3 Seasons",
    "hdsd": "HD",
    "type": "t",
    "desc": "In the midst of an international crisis...",
    "cast": "Keri Russell, Rufus Sewell...",
    "genre": "Political TV Shows, TV Dramas",
    "season": [
      {
        "id": "81946513",
        "s": "Season 1"
      }
    ]
  }
}
Live response
GET /api/playlist/:id Resolve HLS streams ▾

Acquires a play token and resolves it into playable HLS stream URLs at multiple quality levels.

Parameters
id required Video or episode ID (path)
title optional Referrer title name (query)
Response 
{
  "success": true,
  "playlist": [
    {
      "title": "The Diplomat",
      "sources": [
        {
          "file": "https://net52.cc/hls/81772103.m3u8?in=...",
          "label": "Full HD",
          "type": "application/vnd.apple.mpegurl"
        }
      ]
    }
  ]
}
Live response
GET /api/genres List genres ▾

Aggregates genre names from homepage categories and returns a deduplicated list with counts.

Live response
GET /api/genres/:name Items by genre ▾

Returns all unique items matching the given genre name.

Path parameters
name required Genre name, e.g. Drama
